# Social Playtest Promotion Kit Design

Date: 2026-05-23
Project: AI Werewolf public Alpha

## Goal

Create a reusable Chinese promotion kit for the first wave of social sharing. The kit should help the owner publish a natural WeChat Moments post and invite friends to try the Tencent Cloud public Alpha at `https://175.178.199.245`.

The tone is "project showcase plus low-pressure playtest invite": clear enough to show the project is real and playable, modest enough to avoid over-promising a polished public beta.

## Audience

Primary audience:

- Friends and acquaintances on WeChat Moments.
- People who may be curious about AI, games, or personal projects.
- Early testers who can play on mobile and give honest feedback.

Secondary audience:

- Small public social posts on Xiaohongshu, Weibo, or Bilibili dynamic posts.
- Technical or maker friends who care that the project is self-built and deployed.

## Positioning

Use this framing:

- "I built an AI Werewolf game that is now playable online."
- "AI players can speak, take actions, vote, and progress through a game flow."
- "It works on mobile without installing an app."
- "This is still an Alpha playtest, so feedback is welcome."

Avoid this framing:

- A polished commercial launch.
- A stable open beta promise.
- Claims that the AI is always smart or human-like.
- Overly dramatic ad copy.

## Deliverables

The implementation should create one repo-local Markdown artifact, tentatively `docs/promotion/social-playtest-kit.md`, containing:

1. WeChat Moments long copy.
2. WeChat Moments short copy.
3. Screenshot plan with 3 to 5 recommended images and captions.
4. Private-message invite copy.
5. Five focused feedback questions.
6. Public-platform rewrites for Xiaohongshu, Weibo, and Bilibili dynamic posts.
7. A short checklist for publishing the post.

## Content Direction

### WeChat Moments Long Copy

The long copy should read like a real personal project update:

- Open with the project milestone.
- Explain the core playable loop in one or two sentences.
- Mention mobile web play and the Tencent Cloud link.
- Ask for friends to try one round.
- Ask for specific feedback about mobile usability, AI behavior, and the most confusing point.

### WeChat Moments Short Copy

The short copy should be casual and quick to post:

- One short project sentence.
- One short playtest ask.
- One link.
- One feedback prompt.

### Screenshot Plan

The screenshot plan should be practical rather than decorative. Recommended images:

1. Mobile table overview after entering a game.
2. A moment with AI speech or public speech visible.
3. A vote/action moment showing the game is interactive.
4. The identity/role drawer or action feedback, if it looks clean.
5. Optional link/QR style image only if the user wants to make a share card later.

Each screenshot should have a one-line caption suitable for posting.

### Feedback Questions

Questions should be easy for friends to answer after one play session:

1. Did you understand what to do next on mobile?
2. Which screen or step confused you most?
3. Did the AI players feel like they were playing Werewolf?
4. Was anything too slow, too noisy, or too hard to read?
5. Would you play another round after this version improves?

### Public Platform Rewrites

Rewrites should keep the same honest Alpha framing but adjust the hook:

- Xiaohongshu: lighter, curiosity-driven, with tags.
- Weibo: concise, project milestone plus link.
- Bilibili dynamic: maker/devlog tone, suitable for later adding screenshots or a short demo video.

## Publishing Checklist

The final kit should remind the user to:

1. Verify the Tencent Cloud link opens before posting.
2. Use the Tencent Cloud link as the primary link: `https://175.178.199.245`.
3. Mention that the project is an Alpha playtest.
4. Ask for feedback through private messages or comments.
5. Save useful feedback into the project notes after posting.

## Out of Scope

This design does not include:

- Generated posters.
- A QR-code landing image.
- A short video script.
- Paid ad copy.
- A formal press-release style announcement.

These can be added after the first wave of playtest feedback shows what message attracts real testers.

## Success Criteria

The promotion kit is successful if:

- The user can copy and publish a WeChat Moments post without rewriting from scratch.
- The content honestly reflects the current public Alpha state.
- The kit gives testers a clear link and a clear feedback ask.
- The same source material can be lightly adapted to at least two public social platforms.
