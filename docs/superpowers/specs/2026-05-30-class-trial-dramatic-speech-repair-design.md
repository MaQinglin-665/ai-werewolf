# 学级裁判戏剧化发言修复设计

## Goal

让 `学级裁判主题局` 的 AI 发言从“普通狼人杀模板套角色口吻”转向“角色正在学级裁判现场玩狼人杀”。本轮目标是完整打磨发言体验，而不是只修一两个误判：角色感优先、戏剧化更强、狼人杀信息可以稍微绕一点，但不能泄露隐藏身份、编造未公开信息或破坏游戏基本可玩性。

验收采用双重标准：先批量文本样本确认 fallback 和验证误杀明显下降，再抽一局实机边看边听，确认整体像学级裁判现场。

## Scope

本设计只影响 `class-trial` 主题局。普通狼人杀、普通角色卡、非学级裁判语音和通用 AI 行为保持现状。

本轮允许对学级裁判局做有限策略调整，包括预言家、女巫、猎人、狼人等角色在白天更主动制造冲突、抛出身份压力或戏剧化保留信息。但这些调整只能在学级裁判主题入口生效，不能改变普通局的行动合法性和胜利目标。

本轮覆盖：

- 白天发言 prompt 和角色透镜。
- 学级裁判专用发言验证边界。
- 戏剧化身份声明归一化。
- fallback 生成方式。
- 学级裁判主题局的轻量策略偏好。
- 中文发言到 GPT-SoVITS 日语改写的听感风险。

不覆盖：

- 新角色或新板子。
- 原作长台词库。
- 普通狼人杀全局发言风格重做。
- 夜晚行动规则或胜负规则改动。

## Current Problems

当前系统已经有角色卡、角色透镜、打法卡、修复提示、fallback 和 GPT-SoVITS 语音分支。问题不在于“没有人设数据”，而在于人设输出经常被后续安全层吞掉，最后回到较模板化的补救句。

主要问题：

- 学级裁判模板校验过硬，把“站边、票口、理由、逻辑链、信息”等正常狼人杀词也当作模板风险，导致角色化但不命中特定关键词的发言被误杀。
- 女巫等身份声明的自然说法和 claim board 归因不一致，例如“女巫在这里”“药也还在”这类戏剧化表述可能没有被稳定记录，后续角色讨论时反而被判成误读声明。
- fallback 虽然有角色名和角色尾巴，但结构仍像“焦点对象 + 缺口模板 + 角色句式”，容易产生拼接感。
- 角色透镜的硬校验主要依赖关键词命中，和“像角色在玩，而不是塞关键词”的目标冲突。
- Day 1 公共素材太窄时，所有角色会围绕同一个信息缺口复读，角色的不同抓点方式没有被充分放大。

## Design Choice

采用“主题局专用表现层重做”的路线，而不是只调几个正则。

学级裁判局新增一个明确的 `dramatic class trial mode`。这个模式只在 `roleCard.theme === "class-trial"` 或等价主题判断命中时启用。它保留通用安全底线，但把表达层从“狼人杀模板合规”改成“学级裁判角色表演优先”。

普通局仍走现有严格发言校验和 fallback，不受这轮改动影响。

## Architecture

### 1. Dramatic Speech Mode

新增一个小的主题判断和配置层，例如 `isDramaticClassTrialSpeechMode(view)` 或等价 helper。它负责集中回答：

- 当前是否是学级裁判主题局。
- 是否允许更戏剧化表达。
- 哪些验证器应该降权或跳过。
- 哪些硬边界必须保留。

这个判断应被 `speechProviders.ts`、`classTrialCharacterLens.ts`、claim 相关逻辑和 TTS 改写链路复用，避免每个文件散落自己的判断。

### 2. Validation Boundary

学级裁判局的验证器分成两类。

硬拦截仍保留：

- 泄露隐藏身份或系统外信息。
- 编造未公开夜晚信息。
- 引用未来发言、未发言者回应、死人继续发言等时间线错误。
- 明显违反技能事实，例如错误查验、错误用药、错误死亡状态。
- 完全不可解析或破坏游戏的信息。

表达层降权：

- 不再因为出现“站边、票口、理由、逻辑链、信息、态度”等词直接判模板。
- 不再要求角色必须命中特定 `signalKeywords` 才算有角色感。
- 对戏剧化转折、夸张口吻、绕一点的声明默认保留。

模板检查从“词语黑名单”改成“结构重复度和缺少局势锚点”判断。也就是重点拦“任何角色都能说的空泛句”，而不是拦狼人杀常用词。

### 3. Claim Normalization

新增学级裁判专用声明归一化层，位置可以在 `src/game/claims.ts` 内扩展，也可以新建 `src/game/classTrialClaims.ts` 后由 claims 层调用。

它负责把戏剧化声明转成结构化声明，例如：

- “女巫在这里”
- “药还握在我手上”
- “我把这张牌摊到裁判席上”
- “这不是暗示，是我明牌”
- “昨晚的刀口没有从我这里过”

归一化结果只用于系统理解和后续验证，不要求模型按标准狼人杀句式说话。后续角色说“6号跳女巫”“6号明牌女巫”时，验证器应能从归一化结果判断这是合理讨论，而不是误判为编造声明。

### 4. Fallback Rework

学级裁判 fallback 不再使用通用的“焦点对象 + 缺口描述 + 角色尾巴”拼接模板。改为每个角色维护少量“即兴动作”模式。

示例方向：

- 苗木诚：把混乱拉回共同可验证点，给一个暂时结论。
- 雾切响子：冷静指出证据链缺口，不做情绪表演。
- 腐川冬子：先敏感反应，再抓对方话里的刺。
- 黑白熊：嘲讽、拱火、逼迫二选一。
- 江之岛盾子：放大矛盾，制造反转和压迫。
- 塞蕾丝缇雅：优雅下注，讲收益和代价。
- 十神白夜：居高临下设标准，要求别人达标。
- 高松灯：短句、停顿、认真确认一个细节。
- 千早爱音：接住社交气氛，再把焦点转成可讨论问题。

fallback 仍必须绑定当前公开局势，但允许句式更像角色现场反应。目标是即使 fallback，也不要让玩家明显听出“系统补了一句狼人杀模板”。

### 5. Theme-Scoped Strategy Bias

学级裁判局允许轻微改变发言策略，但只影响白天表达和发言计划，不改变行动合法性。

预言家：

- 避免“偏好信息”这类玩家难理解的含糊词。
- 可以选择戏剧化明跳，也可以明确说自己暂时压住身份线，但必须让桌面知道这是一个可追问的动作。

女巫：

- 允许更戏剧化明牌或保留药信息。
- 声明归一化要能理解这些表达。

猎人：

- 可以用更有压迫感的“不要逼我开枪”式压力，但不能越权宣称系统确认。

狼人：

- 可以更主动拱火、反打、制造票口。
- 仍不能泄露狼队信息或使用系统视角。

村民：

- 不只复述身份缺口，要按角色透镜选择不同抓点。

### 6. TTS Rewrite Check

GPT-SoVITS 分支会把中文发言改写成日语。TTS 改写只允许轻微意译，不能丢失狼人杀关键信息。

需要在验收里抽查：

- 中文里的身份声明是否在日语改写后仍能听出。
- 角色语气是否增强，而不是把桌面逻辑洗掉。
- 过长发言是否被改写成难以听懂的长句。

## Data Flow

`roleCard/personas.json` -> `classTrialCharacterLens` -> `dramatic class trial mode` -> DeepSeek speech plan/input -> raw speech -> class-trial validation boundary -> claim normalization -> repair or fallback -> optional GPT-SoVITS rewrite -> UI/audio playback.

关键原则：

- LLM 原文优先保留。
- 校验只拦硬越权和严重不可玩。
- repair 优先要求模型保留戏剧化角色动作。
- fallback 是角色即兴反应，不是普通狼人杀模板补句。

## Error Handling

如果 DeepSeek 输出触发硬拦截，仍走修复重试。

如果只触发表达层问题，例如轻微绕、戏剧化过强、用了常见狼人杀词，不进入 fallback。最多记录诊断信号，供后续评估。

如果 claim normalization 无法确定是否声明身份，采取保守记录：不强行给身份，但后续验证器也不应把“讨论某人的可能声明”直接判死。只有明确编造已经不存在的声明时才拦截。

如果 GPT-SoVITS 或日语改写失败，回退到现有音频 fallback，不影响文本发言显示。

## Testing

新增或更新聚焦测试：

- 学级裁判局使用 dramatic mode，普通局不启用。
- `validateClassTrialGenericSpeechTemplate` 不再因为正常狼人杀词误杀角色化发言。
- 仍能拦截泄露隐藏身份、未来发言、未公开夜晚信息等硬错误。
- “女巫在这里”“药还握在我手上”“我明牌”等戏剧化声明能被归一化。
- 后续角色讨论已归一化声明不会触发错误归因。
- fallback 输出按角色即兴动作生成，不退回通用模板。
- 主题局策略提示中不再使用“偏好信息”这类含糊表述。
- GPT-SoVITS route 在学级裁判角色卡下仍走本地语音分支。

## Acceptance

文本验收：

- 连续跑至少 2 局学级裁判 Day 1 样本。
- fallback 率明显低于当前样本中的 4/9。
- validation failure 主要来自硬越权，不再主要来自模板误杀或声明误归因。
- 9 个角色里至少 7 个能从抓点方式、施压方式或语气动作上明显区分。
- 不出现“信息不多先听后置”“我是闭眼好人”“身份-信息-站边-票口”这类普通模板回潮。

实机验收：

- 本地开一局学级裁判主题局，边看边听至少一轮白天发言。
- 整体听感像学级裁判现场，不像狼人杀复盘播报。
- 允许个别句子绕，但玩家仍能理解当前谁在压谁、为什么压、有没有身份声明。
- TTS 改写没有丢掉关键身份和票口信息。

## Risks

角色优先会降低一部分标准狼人杀表达的清晰度。这个风险是本轮有意接受的，但必须用硬边界保证不破坏游戏。

放宽验证器可能让少量质量一般的原文通过。相比频繁 fallback，当前目标更偏向保留模型原文和角色现场感。

主题局策略放开可能改变局势节奏，例如预言家更早明跳、狼人更强势带票。由于只作用于学级裁判主题局，这属于可接受的体验差异。

fallback 改成角色即兴动作后，需要避免变成固定角色套路。每个角色应有多个动作模板，并优先绑定当前桌面公开焦点。

## Implementation Notes

优先顺序：

1. 建立 dramatic mode 判断和测试。
2. 放宽学级裁判表达层验证，保留硬边界测试。
3. 修 claim normalization 和女巫声明归因。
4. 重做 class-trial fallback。
5. 微调主题局发言策略。
6. 加文本批量样本和实机听感验收记录。

每一步都应保持普通局测试不变，避免把学级裁判的戏剧化规则泄露到默认狼人杀模式。
