# 学级裁判角色行为透镜设计

## Goal

让 `学级裁判主题局` 的角色不只是“说话口吻不同”，而是在白天发言和投票理由里呈现不同的抓点方式、施压方式和解释票口方式。角色仍然认真玩狼人杀，轻微人设偏好不能覆盖公开信息、身份目标、合法行动和胜利目标。

## Scope

本轮只影响本地 `class-trial` 主题下的白天发言生成和投票/行动理由输入。夜晚行动选择暂不加入角色偏好，避免过早影响平衡。非学级裁判主题保持现状。

不引入固定台词库，不复刻原作长台词，不让角色每次自报姓名，也不允许为了角色感泄露隐藏身份、编造未公开信息或违背当前狼人杀局势。

## Design

新增一个独立的 `classTrialCharacterLens` 层，把角色 id / roleCard 转换成稳定的行为信号，而不是继续把长段提示散落在 `speechProviders.ts` 和 `actionProviders.ts` 里。

每个角色 lens 至少包含：

- `attentionBias`: 该角色优先观察的公开矛盾类型。
- `pressureMove`: 该角色常用的施压方式。
- `voteRationaleStyle`: 该角色解释票口或保留态度的方式。
- `forbiddenTemplates`: 该角色下也要避免的狼人杀模板句。
- `sampleCadence`: 简短节奏提示，只描述句式感觉，不放原作台词。

示例方向：

- 苗木诚：先承认不确定，再把矛盾拉回大家能共同验证的点。
- 雾切响子：优先看证据链断点和前后矛盾，少讲情绪。
- 江之岛盾子：戏剧化放大公开矛盾，但不能空喊绝望或只挑衅。
- 黑白熊：可以嘲讽和挑拨，但不能以主持人身份裁定规则。
- 十神白夜：用标准压人，要求对方达标。
- 塞蕾丝缇雅：优雅试探，像下注一样轻压票口。
- 腐川冬子：敏感、防御性强，抓对方含糊和逃避。
- 高松灯：短句、敏感，抓声音里的犹豫和躲闪，但要落到公开矛盾。
- 千早爱音：先社交缓冲，再抓一个具体违和；语气词只做少量转场。

## Data Flow

`roleCard/personas.json` -> `classTrialCharacterLens` -> speech/action LLM input -> DeepSeek output -> existing validation and fallback.

白天发言 input 会得到角色的 `attentionBias`、`pressureMove`、`sampleCadence` 和模板禁用信息。投票/行动 input 会得到 `attentionBias` 和 `voteRationaleStyle`，用来影响投票解释的表达和轻微偏好，但不改变合法行动集合。

## Validation

学级裁判白天发言应至少体现一个角色 lens 信号，例如雾切的证据链断点、苗木的共同验证点、江之岛的挑衅式矛盾放大或高松灯的敏感停顿式追问。

如果 DeepSeek 输出落回通用模板，例如“按现在桌面看”“我先不站死”“我换一个角度”“这个疑点未解除”，验证层应触发一次带角色 lens 的修复重试。最终 fallback 也使用角色 lens，不能退回普通狼人杀模板。

验证仍保留现有边界：只能评价已经公开的信息，不能说出未公开身份、夜间细节、系统事实或尚未发言者已经回应过的内容。

## Testing

需要新增或更新聚焦测试：

- 每个固定学级裁判角色都能生成 lens。
- 白天发言 input 包含角色的抓点和施压方式，而不只有语气描述。
- 投票/行动 input 包含轻微角色偏好和票口解释风格，同时保留胜利目标、合法行动和公开信息边界。
- 通用狼人杀模板句在学级裁判发言中会触发验证错误或修复提示。
- class-trial fallback 使用角色 lens，非 class-trial fallback 行为不变。

## Acceptance

本轮完成后，跑一轮 Day 1 的学级裁判发言，9 个角色里至少 6 个应能明显听出不同的抓点方式，而不是只听出不同口吻。不能出现明显私密信息泄露、长段模板复盘、固定台词库感或千早爱音语气词乱塞。

## Risks

角色 lens 会让部分角色更偏向某些矛盾类型，可能导致个别局里攻击点集中或胜率轻微波动。这个风险通过“轻微偏好、公开信息优先、夜晚行动暂不动”来控制。

如果 lens 写得太强，角色会变成固定套路；如果写得太弱，模板味不会明显下降。第一版应保持每个角色 2-4 条短信号，并依靠 live Day 1 听感继续微调。
