# Alpha 朋友试玩说明

阶段二目标是确认公网房间不是只在自动 smoke 中可用，而是能被真实玩家按链接进入、加入、开局、行动、发言、投票和刷新恢复。

## 试玩入口

- 主公开服务：https://175.178.199.245
- 主试玩说明：https://175.178.199.245/alpha-playtest
- 主反馈模板：https://175.178.199.245/alpha-report
- 主联机房间：https://175.178.199.245/rooms
- 主健康面板：https://175.178.199.245/alpha-health
- 备用镜像：https://ai-werewolf-free.onrender.com

先打开主健康面板，确认 `productionMinimumReady=true`。Render 只作为备用镜像；如果出现免费实例冷启动等待页，等服务唤醒后刷新一次。

## 房主流程

1. 打开 `/rooms`。
2. 输入昵称。
3. 首轮选择 `6人新手局`，降低验证复杂度。
4. 创建房间。
5. 复制房间邀请码或邀请链接发给朋友。
6. 等朋友加入并确认各自座位后开局。
7. 至少完成一次真人夜晚行动、白天发言和投票。

## 朋友流程

1. 打开房主发来的邀请链接。
2. 输入昵称并加入房间。
3. 确认自己看到的是自己的座位和私有身份。
4. 轮到自己行动时，只操作页面当前高亮的行动面板。
5. 中途刷新一次页面，确认能恢复到自己的视角。

## 阶段二验收清单

- 两端能看到同一个房间码。
- 两端能看到同一份玩家列表和在线状态。
- 开局后不同玩家只能看到自己的私有身份。
- 至少一个真人完成夜晚行动。
- 至少完成一轮白天发言。
- 至少完成一轮投票，投票后进入下一阶段或遗言阶段。
- 刷新后能恢复当前玩家视角，或页面给出可理解的重新加入提示。

## 已知限制

- 这是 Alpha 小范围试玩，不是公开运营版本。
- 免费 Render 资源会休眠，首次访问可能慢。
- 当前没有账号、匹配、封禁、付费、公开运营监控和客服流程。
- 阶段二默认使用 mock AI；真实 LLM/TTS 需要单独配置和验证成本。
- 建议先小房间、少量玩家测试，不要公开扩散链接。

## 反馈模板

玩家也可以直接打开 `/alpha-report`，填写后复制反馈文本。

记录问题时优先包含：

- 设备和浏览器。
- 房间码。
- 你是第几号玩家。
- 出问题的阶段。
- 页面提示或报错。
- 刷新后是否恢复。
- 从创建房间开始的最短复现步骤。
