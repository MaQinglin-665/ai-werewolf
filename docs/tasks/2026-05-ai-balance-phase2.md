# 2026-05 AI 胜率平衡二阶段

## 背景

上一轮好人推理增强实验没有整体合入。实验把白天推理指标推高了，但没有提升好人胜率：

- 已提交 baseline：好人胜率 18.9%，狼人胜率 81.1%；好人投狼准确率约 45.0%，误放逐率约 66.8%。
- 未合入实验：好人胜率 16.4%，狼人胜率 83.6%；好人投狼准确率约 50.6%，误放逐率约 58.8%。

结论：好人确实更会从发言、票型、行为矛盾里找狼，但神职生存链和女巫/猎人强动作质量抵消了白天收益。

## 本轮保留

- 模拟统计增加首个放逐指标，用来区分首放逐是狼人、好人、还是好人神职。
- 公开投票视图保留 `reason`，后续 AI 复盘可以看到投票理由。

## 本轮不保留

- 不合入大段 `tableRead` 调参。
- 不合入女巫毒、猎人枪、狼刀权重的实验调参。
- 不把 LLM 发言改成固定模板，不削弱狼人表达和创造性。

## 后续候选

每个候选必须单独验证，不能混在一起：

1. 好人投票证据门槛：只有公开查杀、对跳、票型矛盾、前后站边矛盾、多点压力等强证据足够时才集中票。
2. 夜死预言家遗留视角：第二天以后更重视夜死预言家的验人、站边和投票关系。
3. 女巫毒和猎人枪强证据门槛：只在强证据场景出手，避免低命中强行动作反向削弱好人。

## 合入门槛

- `node scripts/simulate-ai.mjs --games=250 --json` 先跑小样本。
- 小样本通过后，再跑 `node scripts/simulate-ai.mjs --json`。
- 1000 局好人胜率必须高于 18.9%，第一目标 22%+。
- 好人投狼准确率不低于 49%。
- 误放逐率不高于 62%。
- 女巫毒和猎人枪命中率不能明显低于 baseline。
- fallback 必须为 0。
