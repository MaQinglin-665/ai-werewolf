# 路线图

## 当前阶段目标

让项目从“能跑的复杂 MVP”进入“可持续迭代的游戏产品”。

优先级不是继续堆功能，而是先把复杂度切开。

## P0：稳定性和可维护性

- 拆分 `src/components/GameClient.tsx`。
- 为规则引擎补关键阶段测试。
- 明确 AI 只能选择合法动作，不能绕过规则。
- 保证 `npm run test`、`npm run lint`、`npm run build` 可作为基本验收。
- 修复或确认 README/源码中文显示乱码问题。

## P1：AI 对局质量

- 优化 AI 的桌面读法、怀疑值和阵营策略。
- 增强座位记忆，不让 AI 每轮像第一次发言。
- 增加模拟统计，观察狼人/好人胜率、fallback 比例、无效输出比例。
- 复盘页展示 AI 决策依据和失败原因。

## P2：体验升级

- 优化桌面 UI 信息密度。
- 改善主持音频与 AI 语音节奏。
- 增加更自然的发言节奏和可读字幕。
- 加强新手可理解性，但不要把页面做成说明书。

## P3：玩法扩展

- 多板子稳定支持。
- 更多角色。
- 更完整的警长流程。
- 多真人或账号体系。
- 对局存档、筛选和统计。

## 近期建议顺序

1. 前端拆分：先把 `GameClient.tsx` 变小。
2. 规则测试：给已有规则补回归测试。
3. AI 行为：减少 AI 决策漂移和无效输出。
4. 文档清理：修复乱码，补环境变量说明。
